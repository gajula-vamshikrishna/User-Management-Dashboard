# Frontend React Application

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

The application will be available at `http://localhost:3000`

## Features

- **Dashboard**: View all users in a responsive grid
- **User Form**: Create and edit users with validation
- **User Details**: View detailed user information
- **Navigation**: React Router for seamless navigation
- **Responsive Design**: Mobile-friendly interface

## Components

- `Header` - Navigation header with links
- `Dashboard` - Users list with CRUD operations
- `UserForm` - Create/edit user form with validation
- `UserDetails` - Detailed user view

## Services

- `api.js` - API service functions for backend communication

## Styling

Custom CSS with responsive design principles:
- Mobile-first approach
- Grid layouts for user cards
- Form styling with validation states
- Button and input components

## Available Scripts

- `npm start` - Start development server
- `npm run build` - Build for production
- `npm test` - Run tests
- `npm run eject` - Eject from Create React App
